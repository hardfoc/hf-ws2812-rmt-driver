esp_err_t ws2812_control_init ( gpio_num_t  gpio_num,
int  channel 
)

Initialise the RMT peripheral for WS2812 output.

This function must be called once before any LED data is transmitted. On failure everything it allocated is released, so it can be called again.

Parameters
gpio_numGPIO connected to the LED strip.
channelUnused: ESP-IDF v5's RMT driver picks a free channel itself.
Returns
ESP_OK on success, ESP_ERR_INVALID_STATE if already initialised, or an error code from the ESP-IDF drivers.

◆ ws2812_write_leds()

esp_err_t ws2812_write_leds ( struct led_state  new_state)

Send LED colour data.

Sends every LED's colour (green, red, blue[, white], scaled by the brightness) with the Kconfig bit timing, then the reset code that latches the frame. Blocks the calling task until the frame has been transmitted.

Parameters
new_stateDesired LED colours.
Returns
ESP_OK on success, ESP_ERR_INVALID_STATE before ws2812_control_init(), or an ESP-IDF error code.
