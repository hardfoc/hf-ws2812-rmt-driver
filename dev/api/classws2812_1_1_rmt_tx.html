◆ Init()

esp_err_t ws2812::RmtTx::Init ( )
inline

Create and enable the channel if that has not succeeded yet.

The constructor calls this once. A failure (no free channel, invalid GPIO, no memory) no longer aborts: it is returned here and by InitStatus(), the object stays unusable (every transmit returns ESP_ERR_INVALID_STATE), and a later Init() retries.

Returns
ESP_OK when the channel is ready, otherwise the ESP-IDF error.
